# My CI App (Production)

## Логика версионирования
- `versionCode`: Генерируется автоматически на основе количества коммитов в Git (`git rev-list --count HEAD`). Уникален для каждой сборки.
- `versionName`: Формируется как `2.1.{Количество коммитов}` для удобства пользователей.

## Таблица Feature Toggles (Remote Config)
| Название флага | За что отвечает | Значение по умолчанию |
| :--- | :--- | :--- |
| `welcome_text` | Приветственный текст на главном экране | `Привет из Remote Config!` |
| `show_new_feature` | Показывает желтый баннер "Секретная функция" | `false` |
